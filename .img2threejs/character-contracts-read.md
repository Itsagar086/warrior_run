# Character contracts read

- grimoire/character/reconstruction.md  (proportion system in head-units, landmark layout,
  minimal skeleton, stylized material recipes, evidenceRef discipline)
- grimoire/character/likeness_maximization.md (projection-first path)

Routing decision: **reconstruction.md (stylized)**, not likeness_maximization.

Reason: the subject is an original stylised character rendered in flat cel colour, not a
specific real person, and the target is a real-time game model. The projection-first path exists
to put a photograph's own pixels on the mesh; there is no photograph here and no patterned
finish to reproduce, so de-lighting and texture projection would add cost without fidelity.
The rubric's own rule applies: solid albedo for flat paint, reference crop for patterned finish.

Honesty note carried forward: a reference sheet is not a scan. Even with front/back/side, the
result is an approximation in primitives, and per-region confidence is reported rather than any
claim of an exact match.
